# جزایر — ظهور تمدن (ISLANDS — Rise of Civilization)

بازی آنلاین **دونفرهٔ** ساخت تمدن با دنیای سه‌بعدی وکسلی ایزومتریک، رابط فارسی موبایل‌اول و پشتیبانی کامل نصب به‌صورت وب‌اپ (PWA).

اگر به سند بالای پروژه رسیده‌ای، این دقیقاً همان بازی است: دو جزیره، دو بازیکن حقیقی، یک جهان مشترکِ ماندگار.

---

## چه چیزهایی پیاده شده

- **حساب کاربری امن**: ثبت‌نام/ورود با bcrypt، نشست پایدار در دیتابیس، و محدودیت سخت‌گیرانهٔ **دقیقاً دو حساب** (قفل تراکنشی روی جدول).
- **دو جزیرهٔ مجزا** با هویت جغرافیایی متفاوت + سه جزیرهٔ اکتشافی (صخرهٔ آهن/طلا، آب‌سنگ صیادان، جزیرهٔ رس).
- **چندنفرهٔ واقعی**: همگام‌سازی زندهٔ موقعیت/حرکت/قایق/انیمیشن هر دو بازیکن از طریق حلقهٔ سینک سروری (`/api/game/sync`)، وضعیت آنلاین/آفلاین، نام‌نما بالای سر کاراکترها.
- **بقا و چکیدن منابع**: درخت، سنگ، بوتهٔ توت، ماهیگیری ساحلی، سنگ‌آهن و طلا و رس — با اعتبارسنجی سرور (فاصله، کول‌داون، ظرفیت انبار).
- **ساخت‌وساز واقعی**: ۱۵ نوع سازه با مدل سه‌بعدی اختصاصی، پیش‌نمایش شبح، چرخش، اعتبارسنجی زمین (ساحل/صخره/چمن/آب)، هزینهٔ منابع، تخریب با بازپس‌گیری ۵۰٪.
- **اقتصاد و تولید غیرفعال**: مزرعه/کلبهٔ ماهیگیری/چوب‌تراش/سنگ‌بری حتی وقتی آفلاینی تولید می‌کنند؛ جمعیت با ظرفیت مسکن رشد می‌کند و غذا مصرف می‌کند.
- **دریا و قایق‌ها**: اسکله، قایق چوبی و بادبانی — سوارشدن، ترمز دریایی، پیاده‌شدن روی ساحل جزیرهٔ دیگر.
- **داد و ستد**: پیشنهاد معامله با ضد-تقلب تراکنشی (جابه‌جایی اتمیک منابع).
- **گفتگوی درون‌بازی**، نقشهٔ جهان با مهِ کشف‌نشده، صحنه‌های داخلی CSS-art برای چادر/خانه/تالار شهر/کاخ.
- **چرخهٔ روز و شب**، آب متحرک شیدر، ستاره‌ها، ابرها، ذرات، نور شعله‌ها، صداهای کاملاً سنتزشده با WebAudio (اقیانوس، باد، موسیقی، افکت‌ها) + کنترل صدای جداگانه.
- **PWA**: مانیفست، سرویس‌ورکر کش‌کنندهٔ شل برنامه، آیکون‌های maskable، صفحهٔ آفلاین، نصب روی گوشی.
- **ذخیرهٔ ماندگار**: همه‌چیز در PostgreSQL؛ جهان پس از رفرش/قطعی/ری‌استارت باقی می‌ماند.

## اجرا محلی

```bash
cp .env.example .env          # DATABASE_URL را تنظیم کن
npm install
npx drizzle-kit push          # ساخت جدول‌ها
npm run dev                   # یا: npm run build && npm run start
```

سپس `http://localhost:3000` را باز کن.

### ساخت دو حساب و تست دونفره
1. در مرورگر اول (موبایل/ابزار توسعه در حالت گوشی) ثبت‌نام «بازیکن ۱» کن.
2. در پنجرهٔ ناشناس یا مرورگر دوم، «بازیکن ۲» را ثبت‌نام کن.
3. ثبت‌نام سوم با پیام «جهان تکمیل است» رد می‌شود.
4. برای دیدن همدیگر: با اسکله + قایق چوبی به دریا بزن و به جزیرهٔ رقیب سفر کن.

## نصب روی گوشی (PWA)
- **اندروید/کروم**: منوی ⋮ ← «Add to Home screen» / «نصب برنامه».
- **iOS/سافاری**: Share ← «Add to Home Screen».
پس از نصب، بازی تمام‌صفحه و با آیکون خودش اجرا می‌شود. منوی «منو» در بازی هم دکمهٔ نصب دارد (وقتی مرورگر اجازه بدهد).

## استقرار (Deploy)
- روی هر پلتفرم Node (Railway/Render/VPS) با `npm run build && npm run start`.
- دیتابیس PostgreSQL مدیریت‌شده (Neon/Supabase/Railway) کافی است؛ `DATABASE_URL` را تنظیم کن و یک‌بار `npx drizzle-kit push` بزن.
- رایگان/کم‌هزینه: Railway یا Render (پلن رایگان محدودیت خواب/پایداری دارد — فایل/DB رایگان در همهٔ سرویس‌ها دائمی نیست؛ برای جهان ماندگار از دیسک/DB پولی یا VPS ارزان استفاده کن).
- هیچ سرویس پولی اجباری خارجی لازم نیست؛ فونت Vazirmatn از Google Fonts بارگذاری می‌شود (جایگزین: هاست لوکال فونت).

## معماری
```
src/
  app/                 Next.js App Router (صفحه + APIها)
  app/api/auth/*       ثبت‌نام/ورود/خروج (bcrypt + session cookie)
  app/api/game/*       sync, gather, build, chat, trade — سرور-مقتدر
  db/schema.ts         users, sessions, players, buildings, chat, trades, world_meta
  game/config.ts       جهان مشترکِ deterministic (سرور+کلاینت): ارتفاع، بایوم، نودها، کاتالوگ ساختمان
  game/engine.ts       موتور Three.js: زمین instanced، اقیانوان شیدر، روز/شب، دوربین ایزومتریک ثابت
  game/models.ts       مدل‌های وکسلی رویه‌ای (کاراکتر، ۱۵ سازه، قایق‌ها، طبیعت)
  game/audio.ts        صداسازی کاملاً رویه‌ای WebAudio (بدون فایل دارای کپی‌رایت)
  components/Game.tsx  پوستهٔ بازی + حلقهٔ سینک + کنترل‌های لمسی (جیو‌استیک مجازی/تاپ)
  components/panels.tsx رابط فارسی: ساخت، نقشه، گفتگو، منو، داد و ستد، داخلی‌ها
public/sw.js           سرویس‌ورکر PWA
```

## ضدتقلب و امنیت
- محدودیت دو حساب با `LOCK TABLE` در تراکنش.
- همهٔ تغییرات اقتصادی/ساخت فقط روی سرور؛ کسر منابع اتمیک با نگهبان SQL.
- کلمپ سرعت/موقعیت سمت سرور، اعتبارسنجی نوع زمین برای برداشت و ساخت.
- گذرواژه با bcrypt؛ کوکی httpOnly؛ ریت‌لیمیت سادهٔ ورود.

## تست‌ها
- `npx next typegen` / `npm exec tsc -- --noEmit` / `npm run build` همگی سبز.
- تست سرتاسری API: ثبت‌نام دو نفر + رد نفر سوم، گرفتن منابع، ساخت، گفتگو، معاملهٔ تراکنشی (همه انجام و سبز شد).
